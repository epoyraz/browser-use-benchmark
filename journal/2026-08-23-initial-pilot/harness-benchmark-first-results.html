Validity finding

Task 0 is excluded across every model, harness, and repetition. A CAPTCHA in any cell invalidates the whole task for comparison. Here Codex ran v1 first and v2 second; Claude ran v2 first and v1 second. Both order-0 cells passed without a challenge and both order-1 cells met Cloudflare. Those raw outcomes diagnose an order/site-state confound, but none contributes to the benchmark score.

Judge behavior and score interpretation

What Luna judged correctly

  • Both passing cells had evidence showing the selected activity sort and the expected five-item ranking.
  • Codex/v2 was correctly marked incomplete because the list was never retrieved.
  • Claude/v1’s final names were recognized as correct.
  • All four structured judgements parsed successfully; there were no judge errors.

Scoring policy now applied

  • Strict cell verdicts are retained as raw audit evidence, not benchmark scores.
  • If any cell reaches CAPTCHA/human verification, the entire task is excluded across all agents, harnesses, and repetitions.
  • That rule excludes all four pilot cells and both paired timing deltas.
  • The raw 50%/50% split is diagnostic only; zero tasks remain scored.
